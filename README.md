# Blog Post Card ✨

## Description

This project demonstrates how to create a responsive blog post card using HTML and CSS.

The card includes:

- A featured image;
- A blog post title;
- A short excerpt;
- A call-to-action button linking to an external page;
- Custom styling with colors, spacing, borders, and hover effects.

This project is designed to help beginners practice building visually appealing card components commonly used in modern websites and blogs.

## Learning Objective 🎯

By the end of this example, you will be able to:

- Structure content using semantic HTML;
- Display and style images within a card layout;
- Create visually appealing buttons and links;
- Apply CSS properties such as:
  - background-color;
  - margin;
  - padding;
  - border-radius;
  - hover effects;
- Create reusable card-style components;
- Improve page presentation with typography and spacing.

💡 This project is ideal for beginners learning HTML5 and CSS3 fundamentals.

## How to Run (Prerequisites)

To run the project, you only need a modern web browser such as:

- Google Chrome;
- Microsoft Edge;
- Mozilla Firefox;
- Or Safari.

No additional libraries or installations are required.

## Installation

Clone the repository:

git clone https://github.com/willpaes/post-card

Navigate to the project folder:

bash
cd post-card


Open the index.html file in your browser:

bash
start index.html

Or simply double-click the file to launch it.
